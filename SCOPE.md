# Public excerpt scope

This repository was prepared as a separate showcase with fresh history. It contains selected source helpers, an explicitly scoped interactive example, synthetic tests and project documentation.

The complete private application, its historical commits, credentials, environment files, databases, customer/visitor records and deployment configuration are not part of this repository. This public excerpt does not grant access to the private source repository.

The examples do not make live provider requests or modify external systems. Open the project locally to interact with them; GitHub's normal code view does not execute HTML. Screenshots show this public example, not private customer records.

No open-source license is granted. The repository is published for portfolio review; separate permission is required for reuse of code and assets.
